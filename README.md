# 💍 سیستم کارت دعوت عروسی

یک سیستم تحت وب برای مدیریت و ارسال کارت دعوت عروسی با قابلیت رهگیری بازدید مهمان‌ها

## 🚀 ویژگی‌ها

- مدیریت مهمان‌ها (افزودن، حذف، جستجو)
- تولید لینک اختصاصی برای هر مهمان
- رهگیری بازدید (آی‌پی، دستگاه، مرورگر، سیستم عامل)
- آپلود عکس برای هر مهمان
- کارت دعوت دو ستونه (عکس راست + مشخصات چپ)
- ریسپانسیو (نمایش در موبایل و دسکتاپ)
- آماده استقرار روی Render

## 🛠️ نصب و اجرا

```bash
pip install -r requirements.txt
python app.py
